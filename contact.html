Contact LevelUp Wallpapers

Have feedback, a question, or a concern about a wallpaper? You can contact the project through its public GitHub issue tracker.

Send feedback or report an issue

Open a new issue and explain the problem or share your suggestion. For an image-related request, include the wallpaper title and describe the concern.

Contact us on GitHub ↗

GitHub issues are public by default. Do not include passwords, payment details, private documents, or other sensitive personal information.

Copyright or image concerns

If you believe a wallpaper should be reviewed or removed, use the same issue link and identify the image as clearly as possible. Please do not post private personal information in a public issue.
