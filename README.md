# LevelUp Wallpapers — Pages and Monetization Readiness

This package is intentionally flat for GitHub's web uploader: all website files and image assets sit at the repository root. Upload the contents of this folder to the ROOT of `mexiaeon/levelup-wallpapers`.

## Pages added
- `about.html`
- `privacy-policy.html`
- `contact.html`

The main app footer links to all three pages. The contact page links to the project's public GitHub issue tracker. GitHub issues are public; visitors are warned not to submit sensitive information.

## Actual current app behavior
- 12 standalone generated AI wallpaper images, with PNG downloads created in-browser.
- Favorites are stored in browser local storage on the device.
- No account system, third-party analytics, or advertising code is currently integrated.
- GitHub Pages hosts the static site and may process technical request information according to GitHub's privacy statement.

The privacy policy must be updated before enabling AdSense, analytics, or other third-party services. It is a project-specific starter notice, not legal advice or a guarantee of advertising approval.

## Publish updated files
1. Extract the ZIP.
2. Upload all extracted contents to the ROOT of the existing GitHub repository (not into a new folder).
3. Commit directly to `main`.
4. Wait for GitHub Pages to redeploy, then refresh the site or open it in a private window.

This is a PWA website, not a native App Store/Google Play release. Advertising is not active.
